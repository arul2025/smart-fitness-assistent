# 💪 CoachBot A – Smart Fitness Assistance Web App

### Overview
CoachBot A is a **Generative AI-powered fitness assistant** that delivers customized training, nutrition, and recovery guidance for young athletes.  
It uses **Google Gemini 1.5** integrated with **Streamlit** for an interactive web experience.

---

## 🎯 Goals
- Empower youth with AI-based personal training.  
- Provide adaptive fitness plans based on role, sport, and injuries.  
- Encourage safe workouts and smart nutrition.  
- Promote accessibility for athletes in low-resource environments.

---

## 🧠 Technologies
- **Python 3.10+**
- **Streamlit** (UI)
- **Gemini 1.5 API** (Google Generative AI)
- **Pandas** (tabular summaries)
